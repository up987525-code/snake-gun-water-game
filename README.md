# Snake Water Gun Game 🐍💧🔫

A fun Python terminal game similar to Rock-Paper-Scissors.

### How to Play
- 0 for Snake
- 1 for Water  
- 2 for Gun
- 9 to Exit Game

Snake drinks Water, Water damages Gun, Gun kills Snake.

### Features
- Uses random module for computer choice
- check() function to decide winner
- Infinite loop with exit option

### How to Run
python snake_gun_water.py
